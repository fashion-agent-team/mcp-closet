# 면접·발표 옷차림

## 기본
면접에는 어두운 색 슬랙스와 셔츠, 단정한 자켓이 무난하다. 남색·검은색·짙은 회색 정장이면 어느 회사든 실수가 적다.
셔츠는 흰색이나 연한 하늘색이 깔끔하다. 무늬가 크거나 색이 강한 옷은 피한다.

## 피할 것
청바지, 후드티, 맨투맨, 운동화, 반바지처럼 편한 옷은 면접·발표·상견례에 어울리지 않는다.
구김이 많거나 얼룩이 있는 옷은 다른 옷으로 바꾼다.

## 신발
정장에는 검은색이나 짙은 갈색 구두를 신는다. 구두가 없으면 장식 없는 검은 단화가 낫다.
